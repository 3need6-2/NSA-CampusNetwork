# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately.

**Do not open a public issue.** Instead, send a description of the issue to the project maintainers.

Please include:
- Type of vulnerability
- Steps to reproduce
- Potential impact

## Scope

This project is a traffic analysis and visualization system. Security concerns include:

- CSV injection in uploaded files
- XSS in dashboard rendering
- API endpoint abuse
- Exposure of sensitive network data

## Response

We will acknowledge receipt within 48 hours and provide a timeline for a fix.
