# Contributing to NSA-CampusNetwork

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/NSA-CampusNetwork.git`
3. Create a virtual environment: `python -m venv venv`
4. Install dependencies: `pip install -r requirements.txt`
5. Run the app: `python app.py`

## Development Guidelines

- Follow existing code style and conventions
- Add type hints to new functions
- Write tests for new features
- Keep functions focused and single-purpose

## Pull Request Process

1. Create a feature branch from `main`
2. Make your changes with clear commit messages
3. Run existing tests: `make test`
4. Open a PR with a description of changes

## Code Style

- Python: flake8-compliant, black-formatted, isort-ordered
- Line length: 100 characters
- Indentation: 4 spaces

## Questions?

Open an issue for discussion before making significant changes.
