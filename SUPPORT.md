# Support

## Issues

If you encounter any problems with NSA-CampusNetwork, please check the existing issues or open a new one at:

https://github.com/Arbeiter-bit/NSA-CampusNetwork/issues

## Troubleshooting

Before reporting an issue, please review:

- The [Troubleshooting section](README.md#故障排除) in the README
- That you are using a supported Python version (3.8+)
- That all dependencies are installed via `pip install -r requirements.txt`

## Security Vulnerabilities

If you discover a security vulnerability, please follow our [Security Policy](SECURITY.md).
